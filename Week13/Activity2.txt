OS - os library helps Python work with the operating system. It can manage files, folders, and environment settings.
Examples: create folders, get the current working directory.

SYS - sys library gives access to Python system settings and program arguments.
Examples: read command line arguments, exit a program.

NUMPY - is use for numerical and scientific computing. It works with arrays and fast mathematical calculations.
Examples: matrix calculations, data analysis.

pathlib - use to handle file and folder paths in a simple way.
Examples: create file paths, check if a file exists.

datetime - library works with dates and time.
Examples: get the current time, calculate date differences.

logging - records messages while a program runs. It helps track errors and system activity.
Examples: log errors, record program events.

django - is a Python framework used to build full web applications.
Examples: create websites, build database-driven systems.

flask - is a lightweight Python framework for building web applications.
Examples: build small websites, create APIs.

fastapi - is a framework used to build fast APIs with Python.
Examples: create REST APIs, build backend services.

bcrypt - is use to securely hash passwords.
Examples: store encrypted passwords, verify login passwords.

pytest - is use to test Python programs
Examples: test functions, run automated tests

pylint - checks Python code for errors and coding standards
Examples: detect coding mistakes, improve code quality
